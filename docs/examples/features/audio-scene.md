# Audio Scene

Demonstrates audio playback features including spatial and ambient audio.

## Overview

This example shows how to use audio instances and script-controlled audio playback.

## Features

- Audio instances
- Spatial audio (position-based)
- Ambient audio (constant volume)
- Script-controlled playback
