# Auto-Trigger Portal

Demonstrates a portal that automatically triggers when the player approaches.

## Overview

This example shows a portal configured with `autoTrigger: true` that travels immediately when the player enters the trigger radius.

## Features

- Auto-trigger portal
- Trigger radius
- Immediate travel
