# Scene Save - Gamemode Manual

Demonstrates manual save functionality triggered from gamemode scripts.

## Overview

This example shows how to trigger manual saves using `Gamemode.saveGame()`.

## Features

- Manual save triggering
- Gamemode save/load
- State persistence
